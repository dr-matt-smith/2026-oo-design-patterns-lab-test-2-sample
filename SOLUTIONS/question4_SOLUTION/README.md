# Lab test - Question 4

Write a TypeScript class in `/src` to pass all the tests.


## Notes

Until you have created the class, the tests fail with *Cannot find module ... src/ShoppingList.ts* - that is expected.

The hints (`hints.story`) show how to read the tests, and which task to run for each
question.

## Some notes about the class to be written

- The name of the list can be set and retrieved.
- The list can be cleared, and items added.
- If an empty name is submitted (for the list name itself, or for an item to be added to the list) then a string property containing the most recent error is updated 
 -  this most recent error can be retrieved through a getter
