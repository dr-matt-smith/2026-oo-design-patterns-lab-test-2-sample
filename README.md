# OO Design Patterns - Lab Test 2 (SAMPLE)

This is a **sample** of Lab Test 2 for my Object-Oriented Design Patterns module (2026), to help you prepare for the
real lab test.

Each question is a small Deno / TypeScript project. You implement the UML diagram in that question's `/src` folder;
see each question's `README.md` for its task, and `README_TypeScript_correctness.md` for the checks your code must pass.

| Folder       | Task                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| `question1/` | Classes and inheritance: `Vehicle`, `Car`, `Boat` and the `FuelType` enum            |
| `question2/` | Packages: two different `Mouse` classes, in `devices` and `rodents`                  |
| `question3/` | Interfaces: `Car` implementing `Intelligence` and `ElectricHybrid`, plus tests       |
| `SOLUTIONS/` | Worked solutions to all three questions - try the questions yourself first!          |

## Getting started

You need [Deno](https://deno.com/) installed. Then, inside a question folder:

```bash
deno task
```

lists the available tasks (run, type check, format, lint, doc lint, tests, coverage).
